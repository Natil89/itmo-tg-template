# Работа с проектом

Python 3.12, aiogram и PostgreSQL. app/ — приложение; app/handlers/ — Telegram;
app/schedule.py — чтение расписания; app/mcp_* — адаптеры MCP; tests/ — проверки;
scripts/ — инфраструктура; docs/ — учебные материалы.

Запуск: `python -m app`. MCP отдельно: `python -m app.mcp_server`.
Проверки: `python -m pytest -q`, `python -m ruff check .`,
`python -m ruff format --check .`, `python -m pip check`.

Обработчики не содержат SQL и копий схем MCP. Сервер проверяет аргументы;
источник расписания задаёт конфигурация, не пользователь и не модель.
Изменения БД должны быть воспроизводимыми и сохранять существующие данные.
Для новых переменных нужен безопасный пример в .env.example и проверка конфигурации.
Не публиковать .env, токены, пароли, персональные данные и реальные диалоги.

Для текущей задачи пользователь явно разрешил редактирование основного проекта.
