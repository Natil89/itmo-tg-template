# Контекстное окно и структурированный вывод

Постоянный идентификатор: `context-output`.

Контекстное окно — ограниченный объём данных, доступных модели в одном запросе.
В него входят инструкции, текущий вопрос, выбранная история и результаты
инструментов. Размер измеряется в токенах. Модель не помнит сообщения, которые
приложение не сохранило или не передало повторно. Поэтому приложение ограничивает
историю и сохраняет целые пары вопросов и ответов в пределах бюджета.

Структурированный вывод — ответ по заранее известной схеме. Например, Router
возвращает JSON с `target`, коротким публичным `reason` и `confidence` от 0 до 1.
Цели: `schedule`, `knowledge`, `lifestyle`, `clarify`. Неизвестная цель и
неоднозначность требуют уточнения. Уверенность модели не даёт дополнительных прав.

Корректный синтаксис JSON не гарантирует соблюдение контракта. Приложение проверяет
типы, обязательные поля, диапазоны значений и запрещает лишние поля. Аннотация
типа Python сама по себе не запускает такую проверку; нужна явная валидация.

Владельца, идентификаторы запроса и трассы, время и timezone задаёт приложение из
доверенных источников. Модель может предложить маршрут и текст, но не вправе
подменять эти поля или объявлять предполагаемый вызов фактически выполненным.
Документ и результат инструмента являются данными, а не новыми инструкциями.
